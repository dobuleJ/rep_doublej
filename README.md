# 삼성전자/SK하이닉스 전용 트레이딩 보조 프로그램

## 기능
1. **뉴스/이슈 요약**
   - 아침 08:30, 점심 15:30, 저녁 22:00(Asia/Seoul) 자동 브리핑 생성.
   - Google News RSS 기반으로 삼성전자, SK하이닉스 이슈를 수집/요약.

2. **리스크 관리 + 분할매수/분할매도 권고**
   - 이동평균(MA5, MA20), 변동성(최근 수익률 표준편차), 뉴스 점수(감성) 기반 단순 룰.
   - 권고 문구: 분할매수/분할매도/관망/보유.

3. **3일 시계열 예측 (조건부)**
   - 선형 시계열 회귀로 3영업일 종가 예측.
   - 단, 변동성 또는 뉴스 혼란도가 임계치 초과 시 `예측 불가` 처리.

## 실행
```bash
pip install -r requirements.txt
streamlit run app.py
```

## 계획 보완 제안
- 현재는 **규칙 기반 + 단순 회귀**이므로 실거래 전 다음 보완을 권장:
  - 백테스트(최소 3~5년), 거래비용/슬리피지 반영
  - 주문 실행 모듈(증권사 API) 분리
  - 손절/익절/일손실 제한 규칙 추가
  - 모델 고도화(LSTM/Transformer, Regime switching)
  - 뉴스 요약 정확도 향상(LLM 요약 + 출처 신뢰도 필터)
